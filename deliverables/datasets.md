# Datasets

All data is public. The exact versions we used are pinned in the code and recorded in
[../results/data/meta.json](../results/data/meta.json), [../results/data/pg19_meta.json](../results/data/pg19_meta.json)
and [../results/sft/data_meta.json](../results/sft/data_meta.json).

| Dataset | Used for | Official source | What we used |
| --- | --- | --- | --- |
| FineWeb-Edu | pretraining (train / val / test) | <https://huggingface.co/datasets/HuggingFaceFW/fineweb-edu> | subset `sample-10BT`, revision `87f09149ef4734204d70ed1d046ddc9ca3f2b8f9`; 2.0B training tokens, 10.0M validation and 10.0M test tokens |
| PG-19 | long-context test (E4) | <https://github.com/google-deepmind/pg19> and <https://huggingface.co/datasets/deepmind/pg19> | test split, read from the Parquet copy <https://huggingface.co/datasets/emozilla/pg19>; the first 50 books (in the dataset's order) with at least 16,385 tokens; titles in `pg19_meta.json` |
| Alpaca-cleaned | instruction fine-tuning (E7) | <https://huggingface.co/datasets/yahma/alpaca-cleaned> (cleaned version of [Stanford Alpaca](https://github.com/tatsu-lab/stanford_alpaca)) | revision `12567cabf869d7c92e573c7c783905fc160e9639`; 49,570 / 1,081 / 1,075 train / val / test examples |
| MQAR and selective copying | synthetic tests (E2, E3) | generated by [afml/eval/synthetic.py](../afml/eval/synthetic.py), following Zoology and the Mamba paper | no download |

**Why the PG-19 Parquet copy.** The official `deepmind/pg19` loader on Hugging Face needs a loading
script, which recent versions of the `datasets` library refuse to run. `emozilla/pg19` holds the same books
as plain Parquet files.

**How the splits were made.** FineWeb-Edu documents are deduplicated (exact SHA-256 of the text) and split by
a hash of the text: 1% validation, 1% test, the rest training. The tokenizer is fitted on 100,000 training
documents only. Alpaca-cleaned is split the same way (2% validation, 2% test) by a hash of prompt and
response.
